1.	Requirements
$ symfony check:requirements

2.	INSTALLATION 
A.	Projet  “Micro service, Console ou API”
# Utilisation de Symfony CLI
symfony new nom_du_projet
# Utilisation de Composer
	composer create-project symfony/skeleton nom_du_projet

B.	Projet  “web”
	# Utilisation de Symfony CLI
symfony new --webapp nom_du_projet
# Utilisation de Composer
composer create-project symfony/skeleton nom_du_projet
cd nom_du_projet
composer require webapp

C.	Choix de version
# Utilisation de Symfony CLI
symfony new --webapp nom_du_projet --version=lts
# ou
symfony new --webapp nom_du_projet --version=6.4

# Utilisation de Composer
composer create-project symfony/skeleton nom_du_projet 6.4.*
cd nom_du_projet
composer require webapp

symfony console about

4.	SERVER
A.	Lancer le serveur web de développement :
$ php bin/console server:run
$ php bin/console server:run –d # demarrer le server en mode demon
$ symfony server:start –d
$ symfony open:local #ouvrir directement sur le Navigateur
$ php -S 127.0.0.0.1:8000 -t public  
	Stopper le serveur web de développement :
$ CTRL + C
	Security
     $ symfony server:ca:install –force
     $ symfony server:start –no-tls #Retour en http simple
	Server Running:
      $ symfony server:list

	Stopper le serveur web de développement :
     $ CTRL + C
	Gestion DNS / sous Domain
     $ symfony proxy:domain:attach nom_site
     $ symfony proxy:start  #sans oublier la config du Proxy

16.	Test
-	Faire 1 Test
   $  symfony console make:test
   $  php bin/console make:unit-test
$ symfony console  make:functional-test   // Creates a new functional test class

-	Typs de Test
	[TestCase       ] basic PHPUnit tests
	  [KernelTestCase ] basic tests that have access to Symfony services
	  [WebTestCase    ] to run browser-like scenarios, but that don't execute JavaScript code
	  [ApiTestCase    ] to run API-oriented scenarios
	  [PantherTestCase] to run e2e scenarios, using a real-browser or HTTP client and a real web server
-	Executer 1 Test
$   php bin/phpunit #Tous les test
$  php bin/phpunit tests/Form #Tous les test du Dossier Form
$ php bin/phpunit --filter UtilisateurUnitTest –testdox
$  php bin/phpunit tests/Form/UserTypeTest.php #Fichier UserTypeTest.php
-	Couverture de Test
$  php bin/console phpunit  --coverage-html templates\test\coverage
$   ./vendor/bin/phpunit --coverage-html templates/test/coverage
